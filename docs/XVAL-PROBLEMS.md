## 기각(오탐)
- 「민준이 도토리를…」 주격 누락 — 이름+«이»(민준이)가 주격으로 정상.
- 3-1 소수 비교 = 교육과정 위반 — 2022 개정 3-1 「분수와 소수」에 있음.
- 직육면체 부피·겉넓이 = 6-2 — 공식 연결표 6-1-6 「직육면체의 겉넓이와 부피」.
- 시속 = 초등 아님 — 프로젝트 정본 6-2(누적 출제)라 유지.
- 십각기둥·구각뿔 = 범위 밖 — 6-1 각기둥과 각뿔에서 규칙 일반화로 다룸.
- 문장 끝 «몇 묶음?» 등 축약 발문 — 게임 화면 길이 제약(문체 선택).
